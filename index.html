How the Attack Unfolded

A full identity-based attack executed with no malware — just a phishing page and an SSH client.

01
Reconnaissance
Target Identification
Identified Ubuntu Server at 192.168.56.101 with SSH port 22 open. Confirmed password authentication enabled.
